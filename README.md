# DummyReport

Sanitized public portfolio export of a private internal tooling project. This Streamlit app demonstrates an AI-assisted database troubleshooting, reporting, and service-operations portal with fully fictional demo content. All real company references, infrastructure details, credentials, and business documents were removed or replaced with mock data.

## Features
- Login, registration, admin approvals, audit log, and internal messaging
- Demo troubleshooting knowledge base with ownership, pending issues, and autonomous-fix review
- Query builder, AI-assisted SQL drafting, schema explorer, and report export flows
- Portal routing plus a separate ticket-resolution demo workspace
- Mock history, connection profiles, presence tracking, and reviewer workflows

## Setup
```bash
pip install -r requirements.txt
streamlit run app.py
```
